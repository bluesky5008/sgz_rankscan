## digits_rank/ — 순위 숫자 글리프 (RankDigitReader, TASK-04)

회색조 PNG. [tools/harvest_digits.py](../../tools/harvest_digits.py)로 픽스처 순위 셀
(`CELL_RANK` = 행 상단 + (1030, 12, 1110, 52))에서 수확했다(2026-09-28). 판독 규칙과
실측 근거는 [digits.py](../../src/rankscan/vision/digits.py) 모듈 docstring 참조.

- **1~3위 메달 숫자 `medal_<d>.png`**: 금·은·동 메달 위의 큰 숫자(설계의 "금색 1~3"은
  실제 3색). 밝거나(V ≥ 120) 채도가 높은(S ≥ 100, V ≥ 90) 픽셀 bbox + 여유 2px. 셀 회색조
  슬라이딩 NCC로 판독 — 자기 1.000, 같은 메달 다른 프레임(p01_w2) 0.946~0.951, 다른
  메달·흰색 셀 최대 0.690 → 임계 0.8.
- **4위 이후 흰색 숫자 `<d>.png`, 변형 `<d>_<n>.png`**: HSV 마스크(S < 90, V ≥ 130) 연결
  성분 클러스터 bbox. 숫자별 첫 출현을 저장하고, 저장본 대비 NCC < 0.8인 출현을 변형으로
  추가했다(판독은 변형 중 최대 점수, 임계 0.45). 픽스처 33셀 실측: 정답 글리프 최고점
  ≥ 0.816, 다른 숫자 최대 0.764(`8`↔`3`).

템플릿과 테스트 픽스처(`tests/test_rank_digits.py`)가 같은 P-01 스냅샷이므로 실기
일반화는 TASK-08에서 확인한다. 미수확 문자 없음(흰색 0~9 전부).

## user/ · region/ · alliance/ — 식별 템플릿 (IdentityMatcher, 실행 시 자동 생성)

`scan` 실행 중 미등록 세력명·지역·동맹 셀이 등장하면 IdentityMatcher가 크롭을
자동 저장하고 DB `identity_templates`에 등록한다(FR-05). 파일명
`<ns>_<순번>.png`. 이 대장에는 개별 파일을 나열하지 않는다 — 원장은 DB가
소유하며 라벨은 `label` 명령으로 확정한다.

이 세 디렉터리는 **런타임 레지스트리**(DB와 수명 동기)로 git에 커밋하지
않는다(.gitignore). DB(`output/rankscan.db`)를 초기화할 때는 이 디렉터리도
함께 비워야 식별자 번호와 파일이 어긋나지 않는다.
